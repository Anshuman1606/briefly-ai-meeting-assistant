# Long recordings and transcripts

The 100,000-character and 2,000-segment restrictions have been removed. Input capacity is now 20 MiB of UTF-8 transcript text, 200 MiB per audio/video upload, and 12 hours of decoded audio. These are resource limits, not promises about latency or shared-host capacity. For large transcripts, upload TXT, SRT or VTT rather than pasting into the browser.

Every transcript segment participates in analysis. Mistral receives batches of at most 12 segments and approximately 16 KB of serialized source data. Results retain source verification and merge all batch actions, decisions and questions without the former global list truncation. Five overall highlights are selected from verified batch highlights using deterministic ranking. Provider analysis is selective and is not guaranteed to identify every commitment. Without an API key, extractive analysis scans the entire transcript. Questions can retrieve evidence from the final segment as well as the beginning.

Whisper decodes mono 16 kHz audio incrementally in five-minute blocks and preserves recording-wide timestamps. Sarvam retains its 25-second WAV requests. Fixed audio block boundaries can reduce recognition accuracy around a boundary; review source audio for critical wording. Processing time increases with duration, especially on shared CPUs. Raw uploads remain temporarily in PostgreSQL and are removed after successful transcription. The Neon Free database has limited total storage: queue large uploads one at a time and allow transcription to finish before uploading another. Database storage must also accommodate retained transcripts, evidence and indexes.

Transcript results, actions, decisions and questions are paginated in the interface. Library reads defer upload binaries and transcripts. The service still materializes transcript evidence for retrieval and export; high concurrency, multi-gigabyte media and unbounded inputs require a dedicated worker and object storage. Community Cloud can restart or sleep, so a 12-hour input limit is not an uninterrupted execution guarantee. A failed analysis can reuse its saved transcript, but individual analysis batches are not checkpointed.

Regression tests cover a 5,001-segment transcript through the database and worker, retrieval of a final-section fact, 2,400 actions merged from bounded provider requests, Unicode byte limits, media block sizes and recording-wide offsets. Mocked long audio/provider checks verify orchestration, not 12-hour recognition quality or live provider availability.
